# 点击放置游戏 · Tap Idle

一个用单个 HTML 文件做成的点击 / 放置（idle）小游戏，无需任何构建步骤，双击 `index.html` 即可在浏览器游玩。

## 怎么玩
- **点怪**：点击屏幕上的怪物造成伤害、掉金币。
- **买 / 升英雄**：英雄自动打怪（放置收益），越往后越贵越强。
- **军团共鸣（觉醒）**：击破 BOSS 获得「灵魂精华」，把英雄练到整五十级（50/100/150…）后可用精华觉醒，为全队永久加伤。
- **主动技能**：消耗能量释放「狂暴 / 黄金 / 时停」，按英雄总等级逐步解锁；后期可用精华买「技能精通」减少冷却。
- **连击**：快速连点累积连击倍率，停手约 2 秒清零。
- **转生（Prestige）**：到达第 100 关后可转生，获得永久伤害加成；灵魂精华转生后保留。
- 进度自动保存在本机浏览器（localStorage）。

## 部署
本仓库直接由 GitHub Pages 托管：将 `index.html`（配合 `.nojekyll`）放到仓库根目录，在仓库
**Settings → Pages → Source** 选择对应分支的 `/ (root)` 即可。

游戏为纯静态单文件，无任何外部依赖，子路径（如 `https://<user>.github.io/<repo>/`）下也能正常运行。
